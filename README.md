## TP Final - DiabeTrack

DiabeTrack es un proyecto académico que permite realizar predicciones a partir de datos relacionados con la diabetes.

Para su desarrollo se utilizaron distintas herramientas y tecnologías:

- **Python:** lenguaje utilizado para desarrollar el proyecto.
- **Scikit-learn:** desarrollo del modelo de Machine Learning mediante regresión lineal.
- **FastAPI:** creación de la API para recibir datos y devolver predicciones.
- **HTML, CSS y JavaScript:** desarrollo de la interfaz web.
- **Render:** alojamiento del backend.
- **GitHub Pages:** publicación de la aplicación web.
